# Pikaicons Duo Solid

Source: https://pikaicons.com/free-icons
Designer: Ashish Kashyap / Pikaicons
License: https://pikaicons.com/license

Selected icons from the free Duo Solid collection, incorporated into this website. Free personal and commercial use and modification are allowed; attribution is optional. The icons may not be redistributed as a standalone pack or collection.

The SVG sprite contains only icons used by this site. Its paths retain the original currentColor fills; their original opacity values are the default. A CSS variable raises the soft areas to 55 percent opacity on dark surfaces for contrast. category-arrow.svg is a recolored copy of the arrow-down icon.

Dropdown icons use #C2185B for primary shapes and #E18CAD for lighter secondary shapes, via inherited CSS variables.
